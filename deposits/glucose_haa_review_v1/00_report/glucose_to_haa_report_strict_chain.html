Glucose → HAA (hydroxyacetaldehyde / glycolaldehyde)

Fully QM-validated reaction route · r²SCAN-3c / CPCM(water), ORCA 6.1.1 · molecule images rendered directly from the deposited .xyz files · single imaginary mode + exact neutral-SMILES IRC double-end match at every step · unified chained node geometries

Summary

Four elementary steps take open-chain D-glucose to HAA (glycolaldehyde) by aldose-ketose isomerization, two retro-aldol C-C cleavages, and a water-catalysed enol→keto tautomerization. Each step has an ORCA r²SCAN-3c/CPCM transition state with exactly one imaginary frequency and an IRC whose raw endpoints match the exact neutral reactant and product SMILES.

4/4 single-imaginary TS 4/4 exact IRC double-end 4/4 barriers unified chained nodes

Co-products: dihydroxyacetone-enol (step 2) and formaldehyde (step 3); step 4 uses one catalytic water (stripped spectator). All barriers 30-36 kcal/mol (electronic).

Validation protocol & files

  • ORCA 6.1.1, r²SCAN-3c / CPCM(water). Each step: OptTS → NumFreq (one imaginary mode) → IRC; raw IRC endpoints matched to exact neutral canonical SMILES on both sides (RDKit DetermineBonds, charge=0).
