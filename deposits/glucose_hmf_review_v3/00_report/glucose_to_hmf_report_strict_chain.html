Glucose → HMF

Fully QM-validated reaction chain · r²SCAN-3c / CPCM(water), ORCA 6.1.1 · all molecule images rendered directly from the deposited .xyz files · single imaginary mode + exact IRC double-end match at every step · shared node geometry between consecutive steps

Summary

Five elementary steps, each with an ORCA r²SCAN-3c/CPCM transition state carrying exactly one imaginary frequency and an IRC whose endpoints optimize to the exact neutral reactant and product. The structure leaving step n is the same file entering step n+1 (canonical node geometry), so there is no front/back endpoint mismatch.

5/5 single-imaginary TS 5/5 exact IRC double-end 5/5 barriers shared node geometry

Overall C₆H₁₂O₆ → HMF + 3 H₂O, mildly exothermic (−4.6 kcal/mol). Intermediates 2 and 3 are the literature HMF intermediates 3-deoxyglucosone (3-DG) and 3,4-dideoxyglucosone-3-ene (3,4-DGE).
